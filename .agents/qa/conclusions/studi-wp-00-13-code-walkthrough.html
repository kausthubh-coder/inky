How to change the app safely

Find the current owner first. Add a schema when data crosses a boundary, a repository method when truth must persist, a coordinator operation when an effect needs policy, and a UI control only after that owner exists. Reuse the queue, browser, evidence, and lifecycle owners.

Common wrong turn

Do not add an LMS executor, second client state store, alternate queue, generic event bus, evidence service, workflow framework, or retry layer merely because another feature needs the same behavior. Extend the existing narrow owner or leave the capability explicit.

Fastest debugging path: visible symptom → renderer projection → IPC command/read → composition wiring → owning coordinator → repository/event → browser or cloud boundary. For agent failures, inspect normalized session events and the exact active tool set before changing prompts.
