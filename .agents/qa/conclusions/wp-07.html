Delivered

Visible profile setup, password-free app UI, real Pi scan sessions, school and linked-system handoffs, current-page evidence, versioned replay hints, partial preservation, missed-course feedback, and idempotent assignment-to-task projection.

Not hard-coded

There is no Moodle adapter or seeded course list in production. The agent receives one general browser tool set plus narrow recording tools whose boundaries decide what may become durable truth.

The discovery flow

Student saves a local profile

Name, safe school root, schedule, and default permission are stored locally. School credentials stay in the persistent browser session.

Pi observes the visible page

Each course, assignment, linked system, and handoff claim forces a fresh browser snapshot. Claimed text must exist in that snapshot before persistence.

Verified assignments become work

Each assignment creates one stable task origin. The existing permission resolver decides whether it also enters the existing manager queue.

Success writes replay guidance

Only a successful scan writes a versioned Markdown workflow. Partial or failed first scans retain evidence and retry fresh; successful workflows replay from the saved root and re-observe current pages.
