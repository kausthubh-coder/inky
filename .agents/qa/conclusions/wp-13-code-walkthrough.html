Scripts and dependenciesForge configuration

package:win first runs the normal Electron/Vite/Sites build, then Forge packages the same artifacts. Renderer-only dependencies stay out of the production graph.

Forge includes runtime resources and rejects source baggage

Package policyNotices

The package contains Electron output, client assets, Pi/provider packages, icon, and notices. Plans, tests, source, local environment files, Vite cache, and protected Sites sources are excluded.

The composition root chooses packaged paths

Electron main

Packaged execution ignores development URLs, loads the bundled renderer, resolves icons from resources, and keeps mutable locations rooted at app.getPath('userData').

Storage upgrades through one validated backup path

Database open/migrateBackup and restore

An older supported database is copied, migrated, validated with normal repository parsers, manifested, and published before the live database opens at the new schema.

Diagnostics exports an allowlist

Diagnostics policyExport contract

The export receives already bounded runtime/storage/telemetry facts, drops unknown properties, redacts strings again, and writes one JSON document. It never archives userData.

The final gate uses the package, not the source launcher

Electron probe contractUser-like evidence

The executable launches outside the repo, reuses an isolated approved profile, exposes CDP only on loopback for testing, and is driven through semantic UI interactions.
