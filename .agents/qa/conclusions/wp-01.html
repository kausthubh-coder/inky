Every later Studi system now speaks the same language.

WP-01 delivers the shared versioned contracts for assignments, evidence, permissions, tasks, runs, events, browser-tool envelopes, and Electron IPC. The package deliberately contains no storage, agent runtime, browser automation, auth, telemetry, scheduling, or finished product UI.

Delivered

Strict Zod schemas and inferred TypeScript types define the operational vocabulary. Pure functions own legal task transitions, deterministic permission resolution, and per-aggregate event ordering.

Boundary

Electron exposes two named, fixed-channel methods. The renderer cannot select a channel. Main validates requests before handlers and results before returning them.

The runtime journey

A caller imports one generated API type

StudiApi is derived from the registry in shared/ipc.ts. A caller supplies the request schema's input type and receives the result schema's output type; exact method arity is preserved.

The preload exposes only named operations

electron/preload.cts builds a frozen API from that registry. It forwards raw typed input once over the contract-owned channel and exposes no generic send, invoke, or listener primitive.

Main validates at the trust boundary

createIpcHandlerRegistrations parses the raw request exactly once. Invalid renderer data stops here, before the typed handler can run.

The handler sees normalized domain input

The handler receives the request schema's parsed output. It returns the result schema's input, which main validates and transforms exactly once before Electron carries it back.

The renderer receives the final result

The API resolves to the result schema's output without reparsing. Transforming-schema tests prove one transport call, one request transform, one handler call, and one result transform.

Domain decisions stay pure

transitionTask, resolvePermission, and event-order helpers return explicit results without storage, clocks, browser work, or IPC. Later packages can persist their outcomes without reimplementing policy.

Contracts later packages inherit

Versioned records

Persistable records and events carry schema version 1; unknown versions fail closed.

Submission permission

Assignment beats pattern, course, then global. No match means do_not_attempt; only auto_submit may submit.

Safe evidence

Credential-shaped fields and credential-bearing URLs are rejected. Evidence contains references and bounded summaries, not cookies, headers, passwords, or page HTML.

Mutation identity

Future tool mutations carry task, run, tab, idempotency, and expected-page-revision identifiers.
