Actions resolve a ref and return fresh evidence

Action path

current ref → backend DOM node → focus or click through CDP → short settle → new snapshot

Navigation accepts credential-free HTTP or HTTPS URLs. Click, type, select, key press, and wait operate through CDP and return the page state after the action.

5

Submission has its own policy path

Click policyFull tool mapping · 97 lines

Ordinary click rejects names that look like submission controls. Pressing Enter checks the focused control for the same risk. Only browser_submit may allow that action, and its input requires the literal confirmation SUBMIT.

Why this matters: separating the tool name is useful only if ordinary actions cannot perform the same mutation. The subtraction pass found and closed the Enter bypass.

Pi's built-in openai-codex OAuth flow provides the authorization URL. Electron opens it in the system browser. Pi owns the credential file, refresh, provider status, and available model list. Studi never parses or logs the token.
