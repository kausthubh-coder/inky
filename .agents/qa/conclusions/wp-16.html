WP-16 · beta evidence

A scan or assignment now leaves a cost, model, and duration trail.

Private-beta PostHog can answer which model people used, how long a scan took, what it cost when Pi reported usage, and what error they hit. Consented names, emails, and school titles stay. Secrets and the school page stay out.

What you get

Finished scans and assignments emit one typed envelope with model, reasoning, duration, tokens, estimated cost, and the course or assignment the student was in.

What stays local

Passwords, cookies, tokens, page HTML, answers, and school-browser replay. The guest pane still never loads PostHog.

How a run is observed

The student starts work

Scan start or assignment start records the selected model and reasoning. A stale usage meter is cleared so the next finish belongs to this run.

Pi reports usage

Assistant message_end usage and tool calls accumulate on the runtime. Finish reads that snapshot once.

The allowlist builds the envelope

Declared fields pass. Secret-shaped strings become [secret]. Extra keys throw. Clerk name and email attach to the person.

PostHog or opt-out

If analytics is on, the envelope is the inspector row and the outbound event. Turning it off stops both immediately.

Proof: telemetry and diagnostics tests keep school URLs and names, strip password/cookie/token canaries, and reject undeclared fields. Usage tests sum Pi token/cost/tool counts. School-view source still has no PostHog hook.
