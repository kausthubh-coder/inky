The shared schemas define what can cross storage and IPC boundaries. An active lease must have a worker session ID and path. An acquiring lease cannot pretend it already has either.

Manual steering changes one durable ordering value

steerNext

The repository finds the current maximum priority and stores one higher value on the chosen entry inside a transaction. Deadline order remains the default for everything else.

Retained follow-up: WP-07 should preserve that value if discovery re-enqueues the same task without explicitly choosing a new priority.

5

Starting work re-checks policy, then claims one lease

startNextAtomic lease acquisition

ordered entry → fresh permission resolution → singleton lease insert → Pi worker session → task becomes working

A queued permission receipt is evidence, not permanent authority. The coordinator resolves permission again at start time. If permission changed to deny, it cancels the task and moves on. If another worker owns the lease, SQLite rejects the insert.

6

The worker is explicitly linked to the manager

Worker and manager session creation

The coordinator passes the manager session path as the worker's parent. Pi keeps each transcript in its own session file. The SQLite lease stores the worker session identity needed to resume it after restart.

7

The manager agent has three narrow tools

Manager toolscreateManagerSession

inspect queue · steer queued task · cancel task

Pi's built-in shell and filesystem tools stay disabled. The manager cannot start a worker, control Moodle, write SQL, submit schoolwork, or supply permission provenance.

8

Preferences and memories stay separate

Prompt construction

Every manager turn loads all global preference artifacts. It loads only the memory IDs explicitly requested for that turn, under a separate heading. This keeps durable instructions distinct from recalled context.

9

Restart reconciles instead of guessing

Recovery path

An interrupted acquiring lease is released. A fully active lease resumes only if the task is still working. Stale queue rows disappear. Queued tasks without rows are reconstructed after fresh permission resolution.
