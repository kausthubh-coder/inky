1. Worst-case running time

Explain insertion sort and support your answer.

O(n²) — one comparison per pass, worst when the deck is reversed.
2. Why cards?

What is each punched card doing in the machine?

Each card is one record. The machine reads a column and bins them, then restacks.
3. Stable or not?

Is this sort stable? Say why in a sentence.

Stable — equal keys keep their order because a card only moves when the column differs.
