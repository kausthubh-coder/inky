Versioning

Persistable records and every event envelope carry schemaVersion: 1. Unknown versions fail parsing instead of being accepted as current data.

Identifiers and time

IDs are non-empty opaque strings. Times are normalized ISO-8601 strings. Event sequences are non-negative integers and must increase per aggregate.

Safe evidence

Evidence records contain a reference, kind, source target, capture time, and optional digest or summary. Contracts have no password, cookie, authorization header, full page HTML, or raw credential field.

Tool envelope

Every future mutation carries taskId, runId, tabId, idempotencyKey, and expected page revision. WP-01 defines the envelope, not browser actions.

Task state machine

discovered → ignored | queued
queued → working | cancelled
working → needs_user | ready_review | submitting | failed | cancelled
needs_user → working | queued | preserved | cancelled
ready_review → submitting | submitted | preserved | needs_user | cancelled
submitting → submitted | needs_user | working | failed

terminal: ignored | submitted | preserved | failed | cancelled

transitionTask(current, command) is pure. It returns the next state plus an event payload or a typed rejection. It never writes storage, invokes IPC, drives a browser, or reads the clock.

Permission resolution

mode: do_not_attempt | attempt | auto_submit
specificity: assignment > pattern > course > global
tie break: latest updatedAt, then stable rule ID

resolvePermission(assignment, rules) → {
  mode, mayAttempt, maySubmit, matchedRuleId, rationale
}

No rule means do_not_attempt. Only auto_submit yields maySubmit: true. The resolver accepts matching context, not agent opinion; future submit tooling must require its result.

IPC allowlist

getRuntimeInfo: void → RuntimeInfo
getContractManifest: void → ContractManifest

One shared registry owns method name, fixed channel, request schema, and result schema. Main-handler registration and the frozen preload API derive from that registry. The renderer receives named methods only, never send(channel), invoke(channel), or event-listener primitives.

Pass when

  • Every schema accepts canonical examples and rejects wrong versions, malformed IDs/times, unknown enum values, and secret-shaped evidence fields.
  • Every allowed transition is covered; property tests prove all other state/command pairs reject without mutation.
  • Permission properties prove specificity, deterministic ties, safe default, and maySubmit only for auto_submit.
  • Event helpers reject duplicate or decreasing sequence numbers.
  • An IPC snapshot shows only the two named methods and fixed channels; malformed handler results fail validation.
  • No duplicate runtime-info interface or arbitrary channel API remains.
  • WP-00 typecheck, build, Sites, Electron, and clean-room gates remain green.

Fail when

  • Renderer, preload, and main process define independent copies of a contract.
  • An unknown schema version parses as current.
  • An invalid task transition changes state.
  • A broad rule overrides a matching assignment rule, or any non-auto-submit result can submit.
  • IPC exposes a caller-selected channel, unvalidated request, or unvalidated result.
  • The package adds storage, browser, agent, network, or UI behavior outside its boundary.
