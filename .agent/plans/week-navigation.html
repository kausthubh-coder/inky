Browse your school weeks

Based on GitHub codex/week-navigation. The first pass added Monday–Sunday weeks. The second pass made a clean calendar that did not match Studi. This pass rebuilds the board as the paper planner in .agents/.design/desk-week.html.

Plan

  1. Keep complete Monday–Sunday weeks, previous/next, and a return to This week.
  2. Make the board one notebook sheet: ink border, spiral holes, yellow Today marker, class slips.
  3. Spell navigation with the interface. The caption is This / Last / Next week, or “2 weeks ago.” The yellow This week sticky only appears when you have left this week.
  4. Filter the board and its count to the selected week. Keep the greeting and Today marker on the real local date.
  5. Check calendar math, typecheck, browse the preview, then attempt the test-studi feature pass.

Interface

The date range leads. Arrows sit beside it as paper buttons. Homework slips keep their ink border and tilt. Empty days are quiet handwriting. Weekend columns are cream. Today is a yellow header and a yellow date pill.
