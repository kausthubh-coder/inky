Onboarding: mockups

The order and the steps stay as they are: onboarding proves trust and sells, and a paywall comes later. Each mock is the real app screen (same CSS, same Dot and Chalky) with the proposed change on top, made by shoot.mjs. Left is the app today, right is the proposal.

1. Welcome

  • "Nice." answered a name step that no longer exists. Now it greets once, with the name capitalised and editable (click it).
  • Three steps say how Studi works, and the third one is the trust line: you check it and hand it in.
  • Chalky peeks in once, so Learn isn't a surprise later.

2. Connected apps

  • "all actions" and the green pill under every app are gone. Each app says what Dot uses it for.
  • Connected is a quiet tick on the right; the rest have one Connect button. Rows are shorter, so Continue stays on screen.

3. Homework folder

  • Says why Dot wants a folder, and the trust line that it can't open anything outside it (the file tools are bounded to this folder).
  • Suggests Documents\Studi and makes it, so most people press one button. "Choose another" still opens the picker.

Needs a small engine change: create the suggested folder when it doesn't exist.

4. Class link

  • The repeated hint is gone. "I don't have a class site" goes straight into Studi with Learn ready and an empty week.

Your call: should someone without a class site get in? Today they can't.

5. When I find homework

  • Bug: the label said "default" on the middle option while the first one was selected. Now the recommended one is selected.
  • "Leave it to me / I'll leave it alone" read both ways. It becomes "Just tell me about it", and each option says who presses Submit.

6. School sign-in

  • Bug: every earlier question stayed on screen and the one that mattered was below the fold. Now only the current message shows, with its buttons right under it.
  • Earlier answers fold into "What you told me": one line each, so the student sees exactly what Dot will do. Clicking a row goes back to that step.

7. Looking around

  • The disabled "Looking…" button is gone; the message already says it.
  • Classes tick off as Dot finishes them, with what it found. This is the moment that sells, so it should be visible.

Needs the scan to report each class as it finishes (its coverage list may already have this).

8. When the check fails

  • Today the only way out is "Try again", forever. Proposed: say what happened, keep what was found, and offer "Skip for now".

Same decision as step 4.

9. Your week is ready

  • Shows the payoff: how much Dot found and what's next.
  • Says what happens next using the answer from step 5 ("you still press Submit"), instead of "If you told me to…".
  • Three lines say where things are: Homework is Dot, Learn is Chalky, the box at the bottom is chat. This is the paywall's natural spot later.

Instructions in the app

No tour and no popovers. Each character explains its own screen the first time, and both can answer "how do I…" from one page that describes the app.

10. Homework, first visit

  • Dot's line says what the screen is and what to do. It shows until you open an assignment or send a message, then goes back to "Nothing needs you".
  • The chat box suggests "what can you do?".

11. Learn, first visit

  • Chalky introduces itself, says how it differs from Dot, and names the two ways in.

12. "What can you do?"

  • Dot answers from a short "how Studi works" page that is added to Dot's and Chalky's instructions, using the student's real settings (here, "every morning").
  • It ends with suggestions taken from their actual week.
